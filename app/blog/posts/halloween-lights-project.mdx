# Halloween Lights Project
---
I created this Halloween lights project using simple HTML/CSS/JavaScript. It was a fun project that allowed me to combine my love for coding with my love for Halloween decorations. Halloween is one of my favorite holidays, and I wanted to create something that would show that off in my code while having fun with the creative process.

The project features a spooky Halloween theme with animated lights that flicker and change colors. I used CSS animations to create the flickering effect and JavaScript to control the timing and color changes of the lights. The end result is a visually appealing display and I am so proud of the result.

You can check out the project on my GitHub repository [here](https://github.com/angel33la/halloween-project-2026). As well as my live page [here](https://angel33la.github.io/halloween-project-2026/). I hope you enjoy it as much as I enjoyed creating it!
